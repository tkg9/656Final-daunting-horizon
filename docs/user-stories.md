# User stories

Format: **As a** <role>, **I want** <action>, **so that** <outcome>.
Each story becomes a GitHub issue on the team Project board.

First draft from the proposal, for the team to review. Sprint numbers are a
suggestion: reorder in the team discussion, then create the issues.

| ID | Story | Sprint | Issue |
|----|-------|--------|-------|
| US-1 | As a **director**, I want to sign up and log in, so that my productions are private to me and my team. | 1 (done) | |
| US-2 | As a **director**, I want to create a production and paste in its script, so that everyone works from one copy. | 1 (done) | |
| US-3 | As a **director**, I want the AI to draft a breakdown of the script (characters, scenes, props, costumes, set pieces, cues), so that I don't start the breakdown from a blank page. | 1 (done, first version) | |
| US-4 | As a **director**, I want to review each item in the AI breakdown, fix what's wrong, and save the rest, so that mistakes don't reach the crew. | 2 | |
| US-5 | As a **director**, I want the script stored by scene and line, with each character linked to their scenes, so that the rest of the app can point at exact moments in the show. | 2 | |
| US-6 | As a **director**, I want to add members to a production with a role (actor, crew, stage manager), so that each person sees what matters to them. | 2 | |
| US-7 | As a **director**, I want to cast actors in roles, so that each actor knows their part. | 3 | |
| US-8 | As a **director**, I want to schedule rehearsals and choose the scenes to work on, so that only the actors in those scenes are called. | 3 | |
| US-9 | As a **stage manager**, I want to take attendance at each rehearsal, so that I can see who missed what. | 3 | |
| US-10 | As an **actor**, I want to see my scenes, my lines, my rehearsal calls and the director's notes, so that I know when to show up and what to prepare. | 3 | |
| US-11 | As a **stage manager**, I want to track props, costumes, set items and tasks with a status, so that nothing is missing on opening night. | 4 | |
| US-12 | As a **stage manager**, I want to attach lighting, sound and set-change cues to script lines and print the cue sheet, so that the board operators have one reference. | 4 | |
